指标说明

Loss 与 PPL：预测真实文本的能力

Loss 是真实下一个 token 概率的负自然对数平均值，越低越好。PPL = exp(loss)，只在相同分词器、文本和评测方法下比较。这里逐文档评估，分块之间重叠 1 个 token，并包含 EOS；和训练记录中的 packing 评估方法不同。

Top-1 / Top-5：正确 token 排第几

Top-1 是真实 token 得分排第一的比例，Top-5 是排在前五的比例。未知字符映射成同一个 UNK，也可能让命中率虚高。导出报告另外提供排除 UNK 目标后的 loss 和 Top-1。

未知字符比例：模型究竟读懂了多少输入

不在字符词表中的输入会变成 UNK。这个比例高时，模型拿不到原文信息，即使 loss 看起来低，也很难据此评价真正的语言能力。

延迟、速度与显存：运行效率

首 token 延迟从模型开始计算到第一个 token 选出；总速度为生成 token 数除以总生成秒数。计时包含采样并同步 GPU，不含浏览器和网络。显存是 PyTorch 峰值张量分配，包含模型，不等于驱动报告的总占用。短样本波动较大。

重复率与样例：不能替代能力评测

重复二元组比例 = 1 − 不重复相邻 token 对数 / 相邻 token 对总数。更低不一定更正确；随机乱码也可能不重复。两个续写样例只用于诊断，训练文本样例可能被记忆。当前模型没有进行指令微调，无法据此评价通用问答、推理或安全能力。
